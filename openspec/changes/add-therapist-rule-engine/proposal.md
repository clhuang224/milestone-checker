# 提案:add-therapist-rule-engine

## 為什麼要做

這是一個用來實驗 Claude Code 搭配 Angular 開發的專案。原本第一版的構想是給家長/照顧者用的兒童發展里程碑打勾清單(靈感來自 [AgendaLu/piaget-based-child-checklist](https://github.com/AgendaLu/piaget-based-child-checklist))。重新盤點方向後,決定把第一版換成一個**給語言治療師用的臨床規則輔助工具**:

治療師依照自己的臨床經驗,把「哪些觀察項目/評估數值組合在一起代表什麼」寫成規則。系統依照個案身上實際勾選的觀察項目跟填入的評估數值,自動比對這些規則,跳出警示或歸納,並協助組出一段報告用的文字草稿。

原本的家長打勾清單構想**目前擱置**,不是這次 change 的一部分;如果之後要做,會是另一個獨立的 OpenSpec change,不會跟這次的資料模型混在一起。

沿用原本的範圍限定:第一版只涵蓋語言治療師常一起處理的三個領域——**語言(language)、言語(speech/構音)、吞嚥(swallowing/餵食)**。

## 要做什麼

- **個案管理**:治療師可以建立/切換個案(用暱稱或代號識別,不強制要求真實個資欄位)。
- **觀察/評估項目記錄**:每個個案底下可以勾選觀察項目(布林/類別型,例如「有流口水」「構音錯誤」)、也可以填入評估分數(數值型,例如某項測驗分數)。
- **規則(Rule)**:治療師自訂條件 → 動作的規則。
  - 條件可以是「勾選項目的邏輯組合」(A 且 B、A 或 B、巢狀群組),也可以是「數值落在某個區間」,兩種可以混用。
  - 動作是顯示一則警示/歸納文字(例如「建議轉介進一步評估」),並可以選擇性附一段報告用的文字範本片段。
  - 規則存成 [JsonLogic](https://jsonlogic.com/) 格式的 JSON——跟框架無關的通用條件表示法,方便日後備份、分享、甚至換平台。
- **規則編輯器 UI**:App 內建一個簡單的條件列編輯器(欄位 + 運算子 + 值,群組用 AND/OR),治療師不需要手刻 JSON 就能編輯規則;同時支援**匯出/匯入原始 JsonLogic JSON**,給想直接編輯檔案或分享規則集的人用。
- **規則觸發**:個案填完觀察項目/分數後,系統自動跑過所有規則,列出被觸發的警示/歸納。
- **報告草稿產生**:根據已勾選的項目跟被觸發的規則,自動組出一段可編輯的文字草稿,治療師可以修改後複製貼到正式報告系統。
- 畫面上要有明顯、常駐的**「僅供臨床參考,不取代專業判斷」警語**。
- 沒有後端、沒有帳號系統——個案資料跟規則都存在瀏覽器的 `localStorage`;規則額外支援匯出成 JSON 檔案做備份或分享給其他治療師。

## 這次不做的事(範圍外)

- 原本的家長打勾清單/里程碑追蹤構想(擱置,不是這次的一部分)。
- 語言/言語/吞嚥以外的其他治療領域(動作、認知…)。
- 雲端同步、多治療師協作、帳號系統、任何伺服器或資料庫。
- 報告匯出成 PDF/Word 檔——這次先做畫面上可編輯、可複製的文字草稿。
- 規則編輯器一開始先做「條件列 + AND/OR 群組」這個夠用的版本,不追求跟商用 query builder(如 react-querybuilder)一樣完整的功能。
- 內建規則範本的臨床正確性——這次先把機制(規則怎麼寫、怎麼觸發、怎麼變成報告文字)做出來,範例規則要清楚標示是佔位/示意用,需要治療師本人審核、替換過才能當真的臨床邏輯使用。

## 技術方向

規則的儲存/評估格式採用 **JsonLogic**(`json-logic-js` 或效能更好的 `json-logic-engine`)——純 JSON、跟框架無關,不綁定任何特定 UI 套件。畫面上的規則編輯器**自己刻一個簡單版本**,不引入現成的 Angular query builder 套件——調查後發現目前市面上的 Angular query builder(`ngx-query-builder`、`ngx-angular-query-builder` 等 fork)大多兩年以上沒更新,跟 Angular 21 standalone/zoneless 的相容性有風險,不值得為了省一點 UI 工夫換來一個維護風險。

## 參考

- 規則格式:[JsonLogic](https://jsonlogic.com/) 的通用條件表示法。
- 編輯器互動概念參考(不是套件依賴):[react-querybuilder](https://react-querybuilder.js.org/)——它可以把畫面編輯出來的條件匯出成 JsonLogic,這次是借用「條件列 + 群組」這個互動模式自己刻 Angular 版本。
- 原始靈感(僅止於「語言治療師會關注哪些領域」這個概念層面):[AgendaLu/piaget-based-child-checklist](https://github.com/AgendaLu/piaget-based-child-checklist)。
