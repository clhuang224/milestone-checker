# 提案:add-vowel-distinctive-features

## 為什麼要做

音韻歷程要能自動推導，得先有辨異徵性可以比對。目前只有聲母有，韻母與介音完全沒有——所以任何跟母音有關的歷程（母音鼻音化、複韻母簡化、聲隨韻母簡化）都推不出來。

補的過程中發現注音的「韻母」不是同一種東西:單元音、複韻母、聲隨韻母、捲舌韻母、空韻混在同一個類別裡，後面幾類套不進「舌位高低前後＋唇形」。

## 要做什麼

- **單元音補辨異徵性**:舌位高低（四級）、舌位前後、唇形。介音 ㄧㄨㄩ 同樣是單元音，一起補。
- **複合韻母改用韻頭／韻腹／韻尾拆解**:複韻母與聲隨韻母變成同一種結構，只差韻尾種類（`i`／`u`／`n`／`ng`）。它們沒有自己的徵性，徵性來自韻腹。
- **捲舌獨立成一個徵性**:ㄦ 的舌位與 ㄜ 相同，差別只在捲舌。
- **空韻拆成兩個**:`ɿ`（舌尖前，ㄗㄘㄙ 的韻母）與 `ʅ`（舌尖後，ㄓㄔㄕㄖ 的韻母），取代原本單一的 `ㄭ`。
- **內容寫進 `references/taiwan-mandarin-vowels.md`**，由 `pnpm check:references` 守住與程式碼一致。

## 這次不做的事（範圍外）

- **不做推導**:這次只補資料與結構。歷程的推導條件是下一個 change。
- **不替 ɿ／ʅ 決定舌位高低前後**:文獻本身沒有定論（[z̩]、[ɹ̩]、[s͡ɯ] 各家不同），留空並標記為舌尖元音，跟文獻的立場一致。
- **不改構音表排版**:格子表是後續的 change。

## 技術方向

拆解**是建模上的方便，不是語音學主張**——ㄞ 的聲學組成跟「ㄚ 接著 ㄧ 分開念」並不相同。用這個結構是為了讓歷程推導有一致的規則，這一點要寫在 `references/` 裡，避免後來的人誤以為兩者等價。

所有徵性值都是英文 id ＋ 中文顯示對照表，中文只出現在畫面那一層。
