# 提案:add-lang-speech-swallowing-checklist

## 為什麼要做

這是一個用來實驗 Claude Code 搭配 Angular 開發的專案,圍繞一個真實(雖然小)的使用情境:做一個明亮、好用的打勾清單,讓家長/照顧者記錄小朋友的發展里程碑、順便寫下達成日期。

比起一次做完「所有兒童發展面向」,第一版先聚焦在語言治療領域常一起討論的三個相關領域:**語言(language)、言語(speech/構音)、吞嚥(swallowing/餵食)**。之後的 change 可以照同樣的模式加入其他面向(動作、認知、社會情緒…)。

## 要做什麼

- 階層式打勾清單:**大項目 → 子項目**,每個子項目可以打勾標記達成,並記錄達成日期。
- 每個子項目可以選擇性顯示**延伸活動建議**(家長在家可以嘗試的活動)。
- 每個小孩可以有**觀察日誌**,讓家長寫自由格式的文字筆記,不只是打勾。
- 畫面上要有明顯、常駐的**「僅供參考,非診斷工具」警語**。
- 明亮活潑的視覺風格。
- 沒有後端、沒有帳號系統——所有資料存在瀏覽器的 `localStorage`。

## 這次不做的事(範圍外)

- 語言/言語/吞嚥以外的其他發展面向。
- 跨裝置同步(參考專案用網址雜湊分享資料的做法,以後可以考慮,這次不做)。
- 任何伺服器、資料庫、身份驗證。
- 最終定案的臨床里程碑內容——實際的月齡/描述需要可信來源並經過審核;這次 change 只先把結構做出來,內容用示意用的範例資料。

## 參考

概念上參考(不是照搬)[AgendaLu/piaget-based-child-checklist](https://github.com/AgendaLu/piaget-based-child-checklist),涵蓋 0–24 個月、5 個面向,用皮亞傑理論 + WHO/Denver II 百分位數據,技術上是 vanilla JS + Tailwind + D3,純 localStorage、用網址雜湊做跨裝置分享。這個專案是用 Angular 跟自己的範圍/風格重新實作這個概念,不是移植。
