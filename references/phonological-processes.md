# 音韻歷程

程式碼對應 `src/app/data/starter-articulation-processes.ts`。

## 這份清單的來源

**由開發者依臨床經驗定義，不引用任何標準化測驗。**

坊間的標準化測驗（例如各種兒童語音測驗）有版權，內容不能抄進這個專案。所以這裡的歷程定義是治療師自己的臨床判斷，不是文獻引用——這跟規則的 `sourceNote` 是同一種性質:內容的權威來自寫下它的治療師，不是來自某份出版品。

命名沿用這份清單自己的一套（前置化、後置化、不送氣化……）。臨床上也有人寫成前置音化、舌根音化、不送氣音化，意思相同，這裡不特別對齊。

## 清單

| id                    | 名稱             | 說明                                                                    |
| --------------------- | ---------------- | ----------------------------------------------------------------------- |
| `deaspiration`        | 不送氣化         | 送氣音被不送氣音替代，如 ㄆ→ㄅ、ㄊ→ㄉ                                   |
| `fronting`            | 前置化           | 構音部位往前移，如 ㄍ→ㄉ（舌根音變齒槽音）、ㄓ→ㄗ（舌尖後音變舌尖前音） |
| `backing`             | 後置化           | 構音部位往後移，如 ㄉ→ㄍ（齒槽音變舌根音）                              |
| `stopping`            | 塞音化           | 擦音或塞擦音被塞音替代，如 ㄙ→ㄉ                                        |
| `affrication`         | 塞擦音化         | 擦音被塞擦音替代，如 ㄒ→ㄑ                                              |
| `fricativization`     | 擦音化           | 塞音或塞擦音被擦音替代，如 ㄐ→ㄒ、ㄑ→ㄒ                                 |
| `nasalFinalReduction` | 鼻音聲隨韻母簡化 | 鼻音聲隨韻母的鼻音被省略，如 ㄤ→ㄚ                                      |
| `medialDeletion`      | 介音省略         | 省略介音，如 ㄧㄠ→ㄠ                                                    |
| `vowelNasalization`   | 母音鼻音化       | 母音帶上鼻音成分，如 ㄧ→ㄧⁿ、ㄨ→ㄨⁿ                                     |
| `diphthongReduction`  | 複韻母簡化       | 複韻母失去韻尾，如 ㄞ→ㄚ                                                |

## 推導條件

自動推導時，「什麼樣的辨異徵性變化算這一條」的判準。

**一筆錯誤可以同時中多條。** ㄙ→ㄉ 既改了部位（舌尖前→齒槽，往後）也改了方式（擦音→塞音），所以同時算後置化與塞音化，不擇一。

| 歷程             | 判準                                                     |
| ---------------- | -------------------------------------------------------- |
| 不送氣化         | 送氣 → 不送氣                                            |
| 前置化           | 部位在排序上往前移（見 `taiwan-mandarin-consonants.md`） |
| 後置化           | 部位在排序上往後移                                       |
| 塞音化           | 方式 擦音／塞擦音 → 塞音                                 |
| 塞擦音化         | 方式 擦音 → 塞擦音                                       |
| 擦音化           | 方式 塞音／塞擦音 → 擦音                                 |
| 鼻音聲隨韻母簡化 | 目標韻母的韻尾是 `n`／`ng`，錯誤音沒有韻尾               |
| 複韻母簡化       | 目標韻母的韻尾是 `i`／`u`，錯誤音沒有韻尾                |
| 母音鼻音化       | 錯誤音帶鼻音化附加符號，且目標音不是聲調                 |
| 介音省略         | **推導不出來**，見下方                                   |

### 前置化與後置化推導不出來

文獻裡這兩條是**具名的特定替代型態**，靠列舉「目標音集合 → 錯誤音集合」界定，不是位置差的函數。查過的來源沒有一份用座標相減。

而且鄭靜宜（2011）明文警告過機械擴張的後果:把不捲舌化併進前置化「將會增加前置化發生率……就可能產生偏頗」，所以她把它拆開算。

具體的反例是 ㄙ→ㄉ。用排序推會得到「後置化」，但後置化的錯誤音只有 ㄍㄎㄏㄐㄑㄒ，ㄉ 不在其中;鄭靜宜的手冊直接把 ㄙㄨ→ㄊㄨ 當成塞音化的示範例，不附任何位置標籤。

這兩條保留在清單裡，但只能手動貼。

### 介音省略推導不出來

構音記錄的單位是「一個注音符號 → 一個注音符號」，但介音省略是**音節層次**的現象（ㄧㄠ→ㄠ），一個符號對一個符號表達不了。

這條目前只能靠治療師手動貼標籤。要能自動推導，得等記錄單位改成整個音節。

## 註記

### 不捲舌化不列入

ㄓ→ㄗ、ㄕ→ㄙ 這種不捲舌的情形**不當成音韻歷程**。台灣華語的不捲舌是方言性變異，不逕自視為語音缺陷——這也是鄭靜宜把它獨立於前置化之外計算的理由之一。

### 「鼻音」這個限定詞不能省

叫「鼻音聲隨韻母簡化」而不是「聲隨韻母簡化」，因為**聲隨韻母不必然帶鼻音**——例如台語就有非鼻音的聲隨韻母。

### 複韻母簡化與鼻音聲隨韻母簡化是兩條，不是一條

兩者在韻母結構上都是韻尾的變化（見 `taiwan-mandarin-vowels.md`），但**結構相同不代表是同一個歷程**，臨床上分開看。「韻尾脫落」不是現行的說法，不要拿它當統稱。
