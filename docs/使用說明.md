# 使用說明

給語言治療師的操作指南。照著讀一遍，大概十分鐘就能把一個個案從建立到產出報告草稿走完一輪。

---

## ⚠️ 先讀這一段

**不要輸入真實個案資料。**

個案欄位請填**化名或代號**（例如「小美」「A03」），不要填真實姓名、學號、病歷號，也不要在報告草稿裡寫可以辨識出本人的細節。原因很直接：

- 你輸入的所有東西**只存在你這台電腦的瀏覽器裡**，而且是**沒有加密的**。
- **沒有帳號、沒有密碼、沒有登入**。任何人只要能打開這台電腦的這個瀏覽器，就看得到全部內容。
- 資料**不會**傳到任何伺服器，也不會同步到你的其他電腦或手機——但這代表保護它的只有這台機器本身。

另外兩件必須先知道的事：

- **清掉瀏覽器資料就全部消失。** 清除瀏覽紀錄／網站資料、換瀏覽器、用無痕視窗，資料都不會跟著走。
- **沒有備份功能。** 目前唯一能匯出的是「規則」（見〈規則〉一節）。個案、課節紀錄、構音記錄、報告草稿**都沒有辦法匯出或備份**，刪掉就是刪掉。

還有一點：**這是一個實驗性的工具，不是完成品。** 內建的示範規則、示範個案、音韻歷程清單都只是示意內容，**沒有經過臨床審核**，正式使用前請自己確認過或整批換掉。

## 1. 這個工具在做什麼

它幫你做兩件事：

1. **把你自己的臨床判斷寫成規則**，然後在每一次課節紀錄上自動幫你比對，符合的就跳出警示。
2. **把觸發的規則串成一段報告草稿**，讓你在上面改，而不是從空白開始寫。

它**不做**的事：

- **它不做診斷。** 它只是照著你寫下的條件比對你自己輸入的資料，然後把結果攤開來給你看。
- **規則不是任何準則或標準化測驗。** 規則是**你自己的臨床判斷寫下來的樣子**，沒有經過驗證，也沒有引用任何出版品。它會不會漏、會不會誤報，取決於你怎麼寫。
- **它不會取代你的判斷。** 畫面最上方那條黃色提醒不是客套話，它就是這個工具的定位。

音韻歷程的自動推導也是同樣的性質：它只比對**辨異徵性**（部位、方式、送氣、韻尾這些）有沒有變，**不理解語境**。推導結果永遠是給你參考的起點，不是結論。

## 2. 資料存在哪裡

存在你這台電腦的瀏覽器儲存空間裡（localStorage）。整理成一句話：

| 問題               | 答案                                           |
| ------------------ | ---------------------------------------------- |
| 有帳號嗎           | 沒有                                           |
| 資料會上傳嗎       | 不會，一筆都不會離開這台電腦                   |
| 換一台電腦看得到嗎 | 看不到                                         |
| 別人看得到嗎       | 只要他能打開這台電腦的這個瀏覽器，就看得到全部 |
| 清瀏覽器資料會怎樣 | 全部消失，救不回來                             |
| 可以備份嗎         | 只有「規則」可以匯出成檔案，其他都不行         |

所以：**填化名，不填真名。**

## 3. 建立個案

第一次打開時，清單裡已經有一個叫「小美」的**示範個案**，是示意用的假資料，可以直接改，也可以刪掉。

在〈個案一覽〉頁：

1. 輸入**個案暱稱／代號**（必填）——請用化名或代號。
2. 選**生日**（選填）。一填下去，旁邊就會即時顯示算出來的年齡，**年份打錯會馬上看得出來**。
3. 選**性別**（選填）。
4. 按〈建立〉，會直接跳進這個個案的頁面。

進到個案頁後，點標題下面的〈▸ 基本資料〉可以展開補資料：

- **生日**——之後隨時可以改。
- **出生週數**——早產個案才填，足月免填。填了之後，年齡會多顯示一個「（矯正 X 歲 Y 個月）」。
- **性別**——之後隨時可以改。目前沒有任何規則會讀它，記錄它是因為嗓音常模與兒童語言發展的典型值本來就因性別而異，之後的表會需要。

### 為什麼年齡這麼重要

**年齡是「那一次課節當天」算出來的，不是今天算的。**

工具只存生日，年齡是每次要用的時候現算，而且基準日期是**那筆課節紀錄的日期**。所以你三月做的評估，五月才回頭寫報告，規則看到的還是三月當天的月齡——不會因為你晚兩個月寫，個案就莫名其妙跨過了某個年齡門檻。

兩個要注意的地方：

- **沒填生日的個案，用到年齡的規則一律不會成立。** 不是當成 0 歲，是整條規則直接不觸發。個案頁上也會提醒你這件事。
- 矯正齡的算法是工具內建的：**未滿 37 週才做矯正**，而且**矯正後超過 36 個月（3 歲）就自動回到實齡**。各機構作法不一致，這兩個數字是本工具採用的值——如果跟你的作法不同，寫規則時請自己留意，目前畫面上還不能調。

寫規則時，「月齡（實齡）」跟「月齡（矯正齡）」是**兩個分開的欄位**，工具不會替你選。這是刻意的：選錯基準的規則照樣會觸發，只是前提跟你想的不一樣，所以這個選擇留給寫規則的人。

## 4. 建立課節紀錄

一次會面 = 一筆課節紀錄。構音記錄、警示、報告都掛在課節底下，所以同一個個案會累積出一條時間軸，每次的資料都留著自己的日期。

在個案頁的〈課節紀錄〉區塊，點右上角〈＋ 新增課節紀錄〉：

1. 畫面問你「**這次要用哪些表？至少選一張。**」，把要用的表點成藍色。
2. 按〈建立〉。日期預設是今天。

進去之後，標題旁邊有一個**日期欄**可以改成實際的會面日期——改完右邊的「當時 X 歲 Y 個月」會跟著重算。**補記舊課節時記得先改日期**，否則年齡會算成今天的。

### 「評估」跟「治療」怎麼分

**沒有「評估／治療」這個開關，也不需要。** 這件事是靠**你掛了哪些表**表達的：

- 掛了構音評估表 → 這次是評估。
- 掛了 SOAP 之類的療程紀錄表 → 這次是治療。
- 兩張都掛 → 這次兩件事都做了，這很常見，這樣記就不用特別處理。

（目前系統裡**只有「構音評估表」一張表**，所以實務上新增課節時只會看到這一個選項。其他表還沒做，見最後一節。）

### 課節裡的頁籤

進到一筆課節紀錄，上方是一排頁籤：

```
構音評估表 │ 警示 ⚠ 2 │ 報告
```

- **前面**是這次掛上的每一張表，一張一個頁籤。
- **〈警示〉**跟**〈報告〉**是固定的，永遠在最後兩個。它們屬於整筆課節而不是某一張表——一條規則可以同時讀年齡跟好幾張表，而一次課節只寫一份報告。
- 警示頁籤上會直接顯示觸發數量（`警示 ⚠ 2`），沒有觸發就只寫「警示」。

**每一格輸入都是邊打邊存的**，切換頁籤不會弄丟東西，也沒有〈儲存〉按鈕要按。用瀏覽器的上一頁會退回上一個頁籤，不會直接跳出這筆課節。

## 5. 構音評估表

畫面分成四區：**聲母、介音、韻母、聲調**。

**聲母那一區的欄位順序有意義**：由左至右是構音部位由前到後。

| 欄  | 注音     | 部位       |
| --- | -------- | ---------- |
| 1   | ㄅㄆㄇㄈ | 雙唇／唇齒 |
| 2   | ㄗㄘㄙ   | 舌尖前     |
| 3   | ㄉㄊㄋㄌ | 齒槽       |
| 4   | ㄓㄔㄕㄖ | 舌尖後     |
| 5   | ㄐㄑㄒ   | 舌面       |
| 6   | ㄍㄎㄏ   | 舌根       |

**這不是注音的背誦順序**，所以第一次看會覺得位置不太一樣——ㄍㄎㄏ 排在最右邊而不是第三欄。ㄈ 跟 ㄅㄆㄇ 同一欄，雖然它是唇齒不是雙唇。

因為這個順序有意義，這一區不會換行，螢幕太窄時是**整區左右捲動**，不是欄位重排——欄位一重排，部位順序就沒了。把游標移到聲母符號上（有虛線底線的），會跳出它的辨異徵性提示，例如 `雙唇/塞音/不送氣/清音`。

### 怎麼填

**每個音有三組「目標詞 ＋ 錯音」**，兩個小格子並排：

| 格子       | 填什麼                                 |
| ---------- | -------------------------------------- |
| **目標詞** | 你用來誘發這個音的詞，例如「蜘蛛」     |
| **錯音**   | **照你實際聽到的音節寫**，例如「ㄆㄠ」 |

**構音正確就把〈錯音〉留白。** 判斷標準只有一個：**錯音格裡有東西就算一筆錯誤，留白就是正確。**

三組都留白的音會自動從記錄裡移除，不會留下一排空格。

### 錯音要怎麼寫

寫成**你聽到的那個音節**，不是寫「替代成 ㄆ」這種描述。實際例子（來自內建的示範個案）：

| 目標音 | 目標詞 | 錯音  | 系統讀成 |
| ------ | ------ | ----- | -------- |
| ㄓ     | 蜘蛛   | ㄉㄭⁿ | ㄓ→ㄉ    |
| ㄘ     | 菜     | ㄎㄚˋ | ㄘ→ㄎ    |
| ㄞ     | 菜     | ㄚ    | ㄞ→ㄚ    |
| ㄧ     | 衣     | ㄧⁿ   | ㄧ→ㄧⁿ   |

有幾個規矩要知道：

- **只有第一個注音符號會被拿來比對。** 一格記的是「一個目標音」，所以「ㄎㄚˋ」裡系統只看 ㄎ，後面的 ㄚˋ 是給你自己看的脈絡，不影響推導。
- **寫非注音的文字不算錯誤，但也推導不出東西。** 你想寫「含糊」「省略」這種註記可以寫，系統會原樣留著，只是沒東西可以推。
- 標了聲調符號沒關係，不影響第一個符號的比對。

### 鼻音化的上標 ⁿ

母音帶鼻音成分時，在**那個符號正後面**加一個上標小 n：**ㄧⁿ**、**ㄨⁿ**。

- **位置很重要。** `ㄧⁿ` 的鼻音記在 ㄧ 身上；但 `ㄉㄭⁿ` 裡的 ⁿ 是黏在 ㄭ 後面，所以它算 ㄭ 的，不會被誤記成 ㄉ 的。系統只承認**緊接在第一個注音符號後面**的那個 ⁿ。
- **只加一個 ⁿ、其他都沒變也算錯誤**（ㄧ→ㄧⁿ），會被推成「母音鼻音化」。
- **有插入按鈕。** 點進〈錯音〉格子，右邊會浮出一個小小的 `ⁿ` 鈕，按下去就插在**游標所在的位置**——所以要記在哪個符號後面，先把游標移到那裡再按。

## 6. 音韻歷程

構音表格下面就是〈音韻歷程〉區塊，**內容是從上面的格子自動推導出來的**，你不用另外填。它只會列出：歷程名稱，以及示範了這條歷程的目標音。

底下有兩個選項：

### 使用推導結果（預設）

系統照著辨異徵性的變化自己歸類。一筆錯誤**可以同時中好幾條**，系統不會替你二選一——例如 ㄙ→ㄉ 既改了部位也改了方式。

**有三條推導不出來，只能自己貼：**

| 歷程                | 為什麼推不出來                                                                                       |
| ------------------- | ---------------------------------------------------------------------------------------------------- |
| **前置化 / 後置化** | 這兩條在文獻裡是「哪些目標音變成哪些錯誤音」的具名型態，不是把部位座標相減。硬用位置推會膨脹發生率。 |
| **介音省略**        | 這是音節層次的現象（ㄧㄠ→ㄠ），而表格的記錄單位是「一個符號 → 一個符號」，表達不了。                 |

所以：**這三條不會自己出現，需要的話請切到〈自己選〉手動貼。**

### 自己選

點〈自己選〉之後，下面會出現一排可以點的按鈕：左邊是歷程名稱，右邊是可以貼上去的目標音。

- **切過去的時候是空白的，這是故意的。** 它不會先把推導結果填進去讓你改——一個你沒有真的寫下來的歸類，比一個看得出來是空的框更糟。
- 清單只列出**這次表格裡有記錄的音**，而且只列出**對那個音可能發生的歷程**。例如 ㄅ 本身就是塞音，就不會給你「塞音化」這個選項。
- 你貼的標籤**會直接影響規則**。規則讀的是「目前生效的那一份歸類」——你改過就照你的算，沒改就照推導的算。

切回〈使用推導結果〉時，你手動貼的內容會留著，下次再切回〈自己選〉還在。

## 7. 警示與報告草稿

兩者都在課節紀錄的**頁籤列最右邊**，屬於整筆課節。

### 警示

〈警示〉頁列出**目前所有被觸發的規則**，每一條顯示等級、規則名稱，以及你寫的那句話。等級有三種，只影響顏色：

| 等級     | 顏色 |
| -------- | ---- |
| **提示** | 藍   |
| **警示** | 黃   |
| **重要** | 紅   |

沒有東西觸發時會寫「目前沒有規則被觸發」。**「沒有觸發」不等於「沒有問題」**——只代表你寫的規則都沒對上。

警示是**即時重算**的：改一格構音記錄、改個生日、改課節日期，警示馬上跟著變，個案一覽的〈重點〉欄跟頁籤上的數字也會跟著更新。

### 報告草稿

〈報告〉頁把**有附報告範本的那些已觸發規則**，照順序串成一段文字，放在一個可以直接編輯的文字框裡。

- **你的修改會自動存起來**，離開頁面、關掉分頁再回來都還在，而且是**跟這筆課節綁在一起**的，換一筆課節就是另一份草稿，不會把上次的文字留在畫面上。
- **〈重新產生〉**會用目前的規則重新生成，蓋掉框裡的內容。如果你已經改過，框上方會出現橘色提醒「這份草稿已經手動改過，重新產生會蓋掉」，而且按下去會**先跳出確認**才動手。沒改過的話就直接重生成。
- **〈複製〉**把整段文字複製到剪貼簿，貼到你真正要用的報告系統裡。

沒有任何附範本的規則被觸發時，文字框是空的（會顯示提示文字），你也可以直接自己在上面打。

## 8. 規則

規則是這個工具的核心，也是唯一需要你先花點時間設定的地方。

**一條規則 ＝ 條件 → 警示文字（＋可選的報告文字）。**

從**上方導覽列的〈評估表一覽〉→〈跨表規則〉**進去。（用到年齡、或同時讀好幾張表的規則不屬於任何一張表，所以獨立成一列。）

### 規則清單

每條規則顯示名稱和警示文字，右邊三個動作：

- **〈停用〉／〈啟用〉**——停用的規則會標「（已停用）」，**完全不參與比對**。想暫時關掉一條規則但不想刪，用這個。
- **〈編輯〉**
- **〈刪除〉**——會先確認。

### 新增／編輯一條規則

點〈新增規則〉，表單由上而下是：

**規則名稱**（必填）——給你自己看的，會顯示在警示上。

**條件**——這是主要的部分，見下一段。

**警示等級**——提示／警示／重要，只影響顏色。

**啟用**——打勾才會參與比對。

**警示／歸納文字**（必填）——觸發時顯示的那句話。

**報告範本片段**（選填）——這條規則要貢獻給報告草稿的文字。可以塞三個代入值：

| 寫法                  | 代入                       |
| --------------------- | -------------------------- |
| `{{case.label}}`      | 個案的暱稱／代號           |
| `{{assessment.date}}` | 課節日期                   |
| `{{value:欄位ID}}`    | 該項目在這次課節記錄的數值 |

**大括號要寫兩層**，例如 `{{case.label}}`。留白的話這條規則就不會出現在報告草稿裡，只會出現在警示。

**臨床依據**（選填）——寫下你為什麼這樣判斷。這一欄的意義是：交給另一位治療師看的時候，他問的是「你同不同意」，而不是「這出自哪裡」。強烈建議填。

### 條件怎麼組

條件是一個可以往下長的樹。最外層是一個**群組**，選〈全部(AND)〉或〈任一(OR)〉，裡面可以放三種東西：

**① ＋條件** — 一列數值比較：`欄位` `比較符號` `數值`。

目前可選的欄位是**月齡（實齡）**和**月齡（矯正齡）**（其他欄位要等有項目式的表做出來才會出現）。比較符號有 `==` `!=` `>` `>=` `<` `<=`。

> **重要**：**沒有資料的欄位，整條規則不會成立。** 例如個案沒填生日，用到月齡的規則一律不觸發——不會被當成 0 去比大小。

**② ＋適用條件** — 針對「這個個案身上有哪些構音錯誤」的條件。先選比對對象：

- **構音錯誤的目標音**——從注音表挑符號（依聲母／介音／韻母／聲調分組）。
- **音韻歷程**——從音韻歷程清單挑。

再選模式，**兩個模式的意思差很多**：

| 模式     | 意思                                                       |
| -------- | ---------------------------------------------------------- |
| **包含** | 個案身上有勾選的**其中任一項**時成立。                     |
| **排除** | **扣掉勾選的項目之後，個案身上仍然有其他構音錯誤**時成立。 |

**〈排除〉不是「完全沒有這些錯誤」。** 它問的是「把這些放到一邊之後，還剩下東西嗎」。

內建的示範規則就是這樣寫的：條件是「月齡 > 48」**且**「目標音**排除** ㄓㄔㄕㄖ」，意思是「四歲以上，而且**扣掉捲舌音之後仍然有其他構音錯誤**」——如果這個孩子只錯捲舌音，扣掉就什麼都不剩，這條就不會觸發。這正是想要的行為。

畫面上每次選完模式，底下都會用一句話重述它的意思，不確定的時候看那一行。

**一項都沒勾的適用條件不會成立**，會出現橘色提醒告訴你。

**③ ＋群組** — 巢狀的子群組，用來組出「A 而且（B 或 C）」這種條件。可以一直往下疊。

每一列右邊都有〈移除〉。

### 匯出、匯入、分享給別人

規則清單右上角有〈匯出〉和〈匯入〉：

- **〈匯出〉**把**目前全部的規則**存成一個 `rules.json` 檔。這是**整個工具裡唯一的備份手段**，也是把你整套規則交給另一位治療師的方法——他匯入之後，你寫的條件、文字、臨床依據他都拿得到，可以直接挑錯或改。**建議定期匯出留一份。**
- **〈匯入〉**選一個 JSON 檔讀進來。

> ⚠️ **匯入會「取代」你目前所有的規則，不是新增上去。** 按下去之前會跳出確認並告訴你有幾條，但一旦確認，原本的規則就沒了。**匯入別人的檔案之前，先把自己的匯出留一份。**
>
> 檔案格式不對的話會直接擋下來並顯示原因，不會匯進去半套。

匯出的檔案裡**只有規則**，沒有任何個案資料。

## 9. 評估表一覽

從上方導覽列進去。這一頁是「設定每張表要填什麼、以及什麼情況要示警」的入口。

第一列是**〈跨表規則〉**，右邊顯示規則條數，點進去就是上一節的規則清單。

下面每一列是一張評估表，顯示名稱和**「N 筆使用中」**（有幾筆課節紀錄掛了這張表）。

### 可以設定什麼

以目前唯一的**構音評估表**為例，它標著「專用表格，輸入方式由程式提供；可設定它使用的分類目錄」。意思是：

**✅ 可以改的：音韻歷程目錄**

點右邊的〈音韻歷程 →〉進去，這份清單完全歸你管：

- **〈新增歷程〉**——填**名稱**、**說明**（例如「送氣音被不送氣音替代，如 ㄆ→ㄅ」）、**臨床依據**（這個分類背後的臨床理由）。
- 每一條都可以**編輯**或**刪除**（內建的十條也可以）。

改完之後，構音表格底下的〈自己選〉跟規則的〈適用條件〉都會用你這份清單。

> 注意：**自動推導的判準是寫在程式裡的**，不會跟著你新增的歷程走。你新增的歷程只能**手動貼標籤**，也可以拿來寫規則，但系統不會自己推導出它。

**❌ 不能改的：表格本身的輸入方式**

構音評估表長什麼樣子——注音格子的排列、三組「目標詞 ＋ 錯音」、錯音怎麼解讀、辨異徵性的對照——**都是程式提供的，畫面上改不了**。這是刻意的取捨：這種表有自己的輸入方式和自己的推導邏輯，做成可自由編輯只會兩邊都做不好。要改就是改程式。
